ERR 运行时错误代码：

ERR 的值 描述
0复制操作成功。
-1源变量的元素数量（SRC_NELEM）未定义。
-2元素数量与源变量的大小不匹配 —— 源变量的存储器大小被除后有余数。
-3SRC_POS 超出源变量范围。
-4DST_POS 超出目标变量范围。
1CPY_NELEM = 0，不存在要复制的元素（参数可疑，但为有效参数）。
2由于空间不足，并非所有元素都可复制到目标变量，要复制的元素已缩短。

ERR < 0：参数无效，复制操作尚未执行；ERR > 0：参数可疑但有效，复制操作已执行。

使用说明与注意事项：

  • SRC 与 DST 的数据类型均为 ANY，源变量和目标变量的数据类型可以不同；复制操作不会进行有效性检查。
  • 源变量的存储器大小由功能块内部确定（以字节为单位），不同 PLC 平台校正方式不同，存储器大小可能不同；本工具按基本类型标准字节数估算。
  • 元素大小 = 存储器大小 ÷ SRC_NELEM，SRC_NELEM 必须能整除存储器大小。可使用 SIZEOF 功能将 SRC_NELEM 设置为源变量的字节数（此时 1 元素 = 1 字节，位置即字节偏移）。
  • SRC_POS 与 DST_POS 均以 0 到 n 表示：如 ARRAY[5..14] 中 SRC_POS = 2 对应数组下标 7。
  • 无法复制 EBOOL 和 IODDT 中的部分内容。
  • EXTRACT 为「过程」类型功能块：在 M340 / M580 / Quantum / Momentum / Premium 平台可用，未在 IEC 61131-3 中定义，使用前需在 Control Expert 中启用扩展。
